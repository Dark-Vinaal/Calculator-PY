# 🧮 CustomTkinter Modern Calculator

A modern, high-performance **GUI Calculator** built using **Python** and **CustomTkinter**.  
This project transitions away from traditional desktop UIs toward a sleek, "Night Vibe" neumorphic aesthetic, specifically optimized for clean rendering on Linux environments like Arch.

---

## 🚀 Overview

The **CustomTkinter Calculator** is a desktop application designed for speed and style. It replaces the dated look of standard Tkinter/Swing with rounded widgets, smooth hover effects, and a deep-space color palette. 

Beyond basic math, this project serves as a blueprint for building **modern Python GUIs** that look like native applications.

---

## 🧰 Key Features

- 🌑 **Neumorphic "Night" UI** – Deep navy background (`#1A1A2E`) with circular, tactile buttons.
- 🎨 **Color-Coded Logic** – Green accent operators, red destructive actions (Clear/Del), and a high-contrast orange Equals key.
- ⚙️ **Advanced Math Support** – Handles `+`, `-`, `*`, `/`, `%`, and exponentiation (`e^`).
- 📱 **Responsive Grid Layout** – Perfectly aligned 5x4 button matrix using Python's `.grid()` management.
- 🐧 **Arch Linux Ready** – Optimized for High-DPI scaling and tiling window managers (i3, Hyprland, etc.).
- 💡 **Dynamic Theme Support** – Built-in dark mode integration via `customtkinter`.

## 💻 How to Run

1. **Install Dependencies**

   **Windows** :
   ```bash
   pip install customtkinter
   ```
   
   **Linux (Arch)** :
   ```bash
   sudo pacman -S tk
   yay -S python-customtkinter
   ```

1. Clone the Repository:

   ```bash
   git clone https://github.com/Dark-Vinaal/Calculator-PY.git
   cd Calculator-PY
   ```

2. Run the Application:

   ```bash
   python app.py
   ```
